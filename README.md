Programa en C++ para registrar calificaciones, calcular promedios y determinar estudiantes aprobados y reprobados utilizando bucles...
Este Programa es para el centro educativo "La Nueva Escuela", Es un programa sencillo de consola para registrar las calificaciones de un grupo de estudiantes
Solicita la cantidad de estudiantes, Se solicita el nombre de cada estudiantes y 4 calificaciones (cada una entre 0 y 100), se calcula el promedio de cada estudiante y muestra si esta aprobado (70 o mas) o si esta reprobado (Abajo de 70), Al terminar muestra un resumen con la cantidad de estudiantes aprobados y reprobados, promedio general del grupo, nombre y promedio del estudiante con el promedio mas alto, y al final pregunta si desea procesar otro grupo (s/n) si pone s el programa se repite desde el paso 1.
